# Resend Transport Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A buildless Kanboard plugin that registers a `resend` mail transport sending through the Resend HTTP API, configured from an admin-only Settings page.

**Architecture:** `Transport\Resend` implements `Kanboard\Core\Mail\ClientInterface` and POSTs JSON through an injectable `Http\HttpClient` seam (curl by default). `Model\ResendConfig` owns the three settings and key resolution. `Controller\SettingsController` renders/saves the settings page inside the core config layout.

**Tech Stack:** PHP ≥ 8.4, Kanboard v1.2.47, ext-curl, PHPUnit via `testing/run-plugin-tests.sh`.

**Spec:** `docs/superpowers/specs/2026-11-18-resend-design.md`

## Global Constraints

- Buildless: no Composer, no npm, no JS/CSS assets.
- Namespace `Kanboard\Plugin\Resend`; plugin dir and repo root `Resend/`; repo `carmelosantana/kanboard-resend`, branch `main`.
- `plugin.json` version == `getPluginVersion()` == tag; start at `1.0.0`. `kanboard_version` `>=1.2.47`, `php_version` `>=8.4`.
- Settings keys: `resend_api_key`, `resend_from_address`, `resend_from_name`. Env: `RESEND_API_KEY`, `RESEND_API_URL` (default `https://api.resend.com`).
- The API key never appears in rendered HTML (except last 4 chars), log lines, or flash messages.
- Transport never throws out of `sendEmail()`.
- Call `$this->request->getValues()` exactly once per POST: it validates and consumes the single-use CSRF token, so an empty array means CSRF failed (suite gotcha "getValues-twice Forbidden"). Do not also call `checkCSRFForm()`.
- Tests read flash via `session_get('flash')` or a stubbed FlashMessage; run the full suite to completion and check the real test count.
- Commits: no AI attribution.

## Review Focus

1. User display names with `"`, `,` or `<` (e.g. `Doe, "JJ"`) → `from`/`to` must stay a single valid address. Test in Task 2.
2. Resend returns non-JSON (HTML 502 from a proxy) → logged as `HTTP 502` with a trimmed body, no warning/exception. Test in Task 2.
3. Admin pastes the key with surrounding whitespace → stored trimmed. Test in Task 3.
4. Saving the form with the key field blank and "remove" unticked keeps the key; ticking remove with a new key typed → new key wins. Test in Task 3.
5. Non-admin (app manager) hits `resend/save` directly → forbidden, nothing stored. Test in Task 3.
